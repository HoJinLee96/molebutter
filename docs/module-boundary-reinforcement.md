# 모듈 경계 보강 검증

검증일: 2026-10-05. 기준 커밋은 `fd1df25`이며, 이후 모듈 경계와 변경 계약을 보강한 범위 및 실행 결과를 기록한다. 운영 DB에는 적용하지 않았다.

## 구현 범위

- catalog가 상품코드·브랜드·중복·등록명·브랜드 추론·버전 검증을 소유한다. 공개 변경 계약은 문자열 JSON 대신 명시적 입력 타입을 받는다.
- procurement가 검색어 검증과 최초 검색어 설정을 소유한다. app은 권한·HTTP 입력 변환과 기존 순서의 동기 연결을 담당하며 상품 업무 SQL을 직접 실행하지 않는다.
- catalog 가드는 실제 트랜잭션·DataSource 참여·쓰기 가능 여부·잠금 획득을 검사한다. 상태는 현재 트랜잭션 synchronization에 귀속되며 공유→배타 승격과 가드 행 누락을 거절한다.
- catalog 변경, procurement 통합/삭제 참여와 inventory 참조 통합은 배타 가드가 있는 바깥 트랜잭션에 참여한다. 조회·변경 대상과 수정 결과를 검사하며 합법적인 동일 값 저장·이력 없는 이동은 허용한다.
- 공개 API의 내부 타입 노출, 알려지지 않은 업무 패키지, Maven 모듈과 패키지 소유자 불일치 및 순환을 검사한다. 제네릭 경계와 잘못된 계약을 포함한 음성 사례를 유지한다.
- HTTP 전용 상품 DTO를 app으로 옮기고 조회 조합을 `ProcurementProductView`로 명확히 했다. 동일한 문자열 검증·코드 정규화는 공통 기능을 사용하고 불필요한 Store 기능·생성자·import를 정리했다.

## 실행 결과

| 검증 | 결과 |
|---|---|
| 기준점 Java 전체 실행 | 448개 통과, 실패·오류·건너뜀 0 |
| 보강 후 Java 전체 실행 | 454개 통과, 실패·오류·건너뜀 0 |
| JavaScript | 기존 47개 모두 통과 |
| 상품·설정 브라우저 | 1440px·390px 대표 흐름 통과 |
| 재고 브라우저 | 1440px·390px 주문·부분입고·재시도·수정·취소·권한 흐름 통과 |
| 알림 브라우저 | 1440px·390px 진입·이동·삭제 실패/재시도·키보드 흐름 통과 |

| 배포 자료 제외 | 비밀 설정·테스트 자료·테스트 JAR·ArchUnit 미포함 확인 |
| Git diff | 공백 오류 없음 |

새 저장소의 첫 패키징 이후 테스트 실행 플러그인을 추가로 받아 전체 검증했다. 빌드가 화면 테스트 자료를 재생성하는 동안 실행한 최초 브라우저 검증은 중단됐으며, 전체 Java 실행이 끝난 뒤 세 화면을 모두 다시 실행해 통과했다. 외부 쇼핑몰 호출은 브라우저 모의 API로 대체했다.

추가한 Java 검증 6개는 직접 변경 계약 검증, 잠금·트랜잭션 거절 조건, 트랜잭션 분리/복원, 가드 행/DataSource 오류, 브랜드 추론의 기존 코드 보존, 아키텍처 규칙 음성 사례다. 기존 통합 실패 검증도 마지막 참여 단계 실패를 주입하도록 강화해 상품·매입처·재고·이력의 전체 롤백을 확인했다.

## 유지 범위와 한계

HTTP 경로·JSON 필드, 권한·CSRF·금액 비노출, ID·버전·중복 요청·수량·잠금 순서를 유지한다. 기준 상품 코드만 브랜드 추론 과정에서 자동 변경하는 동작은 추가하지 않는다. 빈 DB 및 기존 데이터 이전 검증도 전체 Java 실행에 포함한다.

DB 구조·기존 Flyway 자료·V29/V30·템플릿·정적 파일·라이브러리 버전은 변경하지 않았다. 신규 트랜잭션 관리자·잠금 최적화·외부 판매 마켓 기능은 추가하지 않는다. SQL 쓰기 소유권은 아키텍처 검사만으로 증명되지 않으므로 [모듈 구조의 쓰기 검토 목록](modular-architecture.md)을 함께 대조한다. 운영 DB와 실제 외부 계정 검증은 이번 범위에 포함하지 않는다.
