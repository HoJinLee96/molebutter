# DB 책임 분리와 다중 모듈 전환 검증

최초 검증일: 2026-10-04. 기준 커밋은 `166c5b1`이며, 당시 작업 트리의 변경으로 검증했다. 운영 DB와 기존 실행 앱은 변경하지 않았다. 최초 검증 당시에는 스테이징·커밋·푸시·PR 생성도 수행하지 않았다.

모든 DB 검증은 별도 임시 MySQL·Redis에서 수행했다. 외부 쇼핑몰·판매 마켓·메일 실호출은 하지 않았다. 브라우저 검증은 실제 Thymeleaf 자원과 모의 API를 사용하며 서버의 수량·동시성 검증은 Java 통합 테스트가 담당한다.

추가된 다섯 검증은 모듈 경계 검사, 상품 통합 중 실패의 전체 롤백, 통합·입고 동시 처리, 100개 상품 목록의 조회 수·페이지 처리, 워커 상태 변경의 일관성 가드 대기다. 기존 테스트 파일은 모두 유지했고 기존 마이그레이션 검증에 V29·V30 사례를 확장했다.

## 이전과 데이터 보존

빈 DB에서는 실행 JAR이 V1부터 V30까지 적용된 뒤 HTTP 로그인 화면과 CSRF 토큰을 제공하는 것을 확인했다. V28 자료를 준비한 임시 DB에서는 V29 이전·대조와 V30 기존 컬럼 제거를 검증했다.

- 삭제·통합 상품을 포함한 전체 상품의 대응 행과 원래 ID·버전을 유지했다.
- 검색 설정·조회 결과·이전 정상 결과·이미지, SQL NULL과 JSON null, 설정·실행 상태·시각을 대조했다.
- 기존 매입·재고 수량·금액·참조를 보존했다. 미확인·0원·큰 금액은 기존 재고 회귀 검증으로 확인했다.
- 활성 작업이 있으면 V29가 첫 DDL 전에 거절했다. V29 이후 값을 의도적으로 바꾸면 V30이 기존 컬럼 삭제 전에 거절했다.
- MySQL DDL의 전체 롤백을 가정하지 않았다. 의도적 실패 이후의 `Flyway.repair()`는 원인을 복구한 격리 테스트 DB에만 사용했다.

## 업무 경계와 회귀

ArchUnit으로 허용 모듈 의존성·공개 API 접근·업무 패키지 순환을 검사했다. SQL 쓰기는 소유 모듈별 목록과 코드 대조로 확인했다. catalog가 기준 상품과 수정 버전을 변경하고 procurement가 검색·조회·워커 상태를 변경한다. inventory의 선택적 판매글 확인과 업무 알림 대상 확인은 app 연결 포트를 사용한다.

상품 통합의 후반 단계에서 오류를 발생시켜 기준 상품·매입처·재고·이력이 함께 롤백되는 것을 확인했다. 통합과 입고를 동시에 실행해 수량·버전 충돌을 확인했다. 워커 임대 갱신·검색 완료·차단·간격 갱신도 기존 잠금 범위를 유지하며 `일관성 가드 → 실행 상태 행` 순서를 따른다.

기존 권한·CSRF·최신 계정 검사·근태 사용자 잠금·금액 비노출·중복 요청·수량 제한·기록 취소·삭제 제한과 알림·감사의 트랜잭션 검증을 유지했다. 이전 조회 결과 차단, 검색 실패·재시도·취소·게이트와 선정 스냅샷을 포함한 복구 판정도 통과했다. 20개와 100개 상품 조회의 SQL 수는 같고 10회 미만이며 전체 건수·다음 페이지 결과를 확인했다.

## 실행 호환과 제외 자료

기존 애플리케이션 자원 64개와 과거 Java 마이그레이션 2개의 내용을 바이트 단위로 대조해 변경이 없음을 확인했다. 기존 HTTP 경로 선언도 유지했다. Flyway·설정·템플릿·정적 파일은 app으로 이동했다.

최종 JAR에서 업무 모듈·마이그레이션·화면 자원 로딩을 확인했다. 비밀 설정·응답 테스트 자료·테스트 JAR·ArchUnit은 포함되지 않았다. 패키징된 JAR의 `PropertiesLauncher`로 두 상태 복구 명령의 미리보기도 실행했다. 기존 Java·Spring Boot·라이브러리 버전은 유지했다.

재현 명령과 테스트 범위는 [테스트 실행](testing.md), 모듈 계약·SQL 소유권과 앱 중지·백업·적용·복구 절차는 [업무 모듈과 DB 책임](modular-architecture.md)에 기록했다. 운영 적용과 외부 마켓 연동은 이번 검증에 포함하지 않았다.

실행 JAR에는 업무 모듈 7개가 포함되며 비밀 설정·테스트 자료·테스트 JAR·ArchUnit은 포함되지 않았다. 모듈 코드·빌드·검증 도구와 문서는 별도 커밋으로 정리한다. 운영 적용이나 외부 서비스 호출은 수행하지 않았다.
