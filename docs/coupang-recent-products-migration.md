# V52 최근 등록상품 수집 전환

V52는 `coupang_collection_recent`와 `coupang_collection_candidate`를 추가한다. V1~V51과 기존 상품·작업본·이력·파일은 수정하지 않는다. 운영 적용은 이 기능 구현과 별개이며, 일반 앱 기동으로 데이터가 있는 DB를 자동 전환하지 않는다.

1. 앱·모든 워커를 중지하고 활성 수집·전송 및 임대가 없는지 확인한다. V51까지 완료된 DB만 전환한다.
2. 현재 소스의 검증된 패키지를 별도 빌드 경로로 준비한다. 기존 비밀 설정 파일을 직접 열거나 수정하지 않는다.
3. `MOLEBUTTER_UPGRADE_JAR`에 준비한 패키지를 지정하고 `bash scripts/upgrade-coupang-recent-products.sh --apply <새 백업 디렉터리>`를 실행한다. 이는 명시적 운영 적용 요청이 있을 때만 수행한다.
4. 명령은 전체 DB·전용 이미지 파일을 백업하고 임시 MySQL에 전체 복원한 뒤 행 지문·파일 바이트·기존 감사 자료를 대조한다. 검증이 통과한 뒤에만 V52를 적용하고 기존 데이터 보존을 재검사한다.
5. `UPGRADE_COMPLETE`와 전후 검증 자료를 확인한 뒤 앱을 시작한다. 중단·실패 기록이 있으면 자동 repair나 앱 재기동을 하지 않고 백업·진단 자료를 보존한다. 복구 시 전체 DB·전용 파일을 검증된 백업 기준으로 복원한다.

검증 전용 `scripts/test-coupang-recent-products-upgrade.sh`는 합성 데이터·임시 DB·임시 이미지로 백업/격리 복원/적용/재실행을 검사한다. 운영 DB와 실제 쿠팡·R2에는 연결하지 않는다.
