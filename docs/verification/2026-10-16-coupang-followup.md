# 쿠팡 작업본·전송 후속 재검토 — 2026-10-16

[직전 재검토의 4건](2026-10-16-coupang-rereview.md)을 다시 검사했다. 완료된 수정 의도의 재저장 방지, 중복 URL·설명의 ID 보존, 서류 두 경로와 인증 누락 필드의 원문 보존 검사는 계속 통과했다. 추가 경로에서 아래 3건을 재현하고 수정했다.

## 재현과 수정

| 우선순위 | 재현 조건과 문제 | 수정 |
|---|---|---|
| P1 | 임시 저장 응답을 지연한 상태에서 전송 완료 목록을 갱신하면 완료 처리가 저장의 입력 잠금을 먼저 해제한다. 응답 전 새 입력이 가능해지고 저장 응답의 재렌더링에 덮일 수 있다. | 임시 저장과 전송 처리의 잠금을 각각 유지한다. 저장 revision이 바뀌면 완료 상태를 다시 확인해 이전 revision 때문에 보류한 완료 처리도 재개한다. |
| P1 | 저장 작업본이 있는 상품의 최신 조회에 편집 형식에서 지원하지 않는 이미지 주소가 있으면 작업본 진입 자체가 실패한다. | 최신 조회를 별도 문서에서 변환·검증한 뒤에만 기준값으로 교체한다. 실패 시 저장 문서와 입력을 복구하고 서버 observation을 비워 전송 준비를 차단한다. |

수정 전 `test-coupang-save-settlement.cjs`에서 입력 잠금 assertion 실패, `unsupportedFreshMediaKeepsTheSavedDocumentAvailableForRecovery`에서 이미지 검증 오류, `attributesWithTheSameNameUseExposureAsPartOfTheirIdentity`에서 중복 속성 오류를 확인했다. 수정 후 동일 검사가 통과했다. 속성 검사는 해당 구매 행의 권한이 false이고 검색 행의 권한만 true인 경우 쓰기를 차단하는 것도 확인한다.

## 단순화와 유지 범위

- 속성 권한 검사를 최신 원문 패치로 통합하고 중복 DTO 권한 검사를 제거했다. 상품·옵션 식별자와 계정·revision·UNKNOWN 보호는 유지한다.
- `sameMapping` 단순 래퍼, 불필요한 옵션 복사와 사용하지 않는 조회·목록 지역변수를 제거했다.
- 현재 화면·API·저장 모델에서 판매용 내부 상품·연결 후보·기준값·비교 실행 계층의 재도입은 확인되지 않았다. 옵션 UUID와 외부 옵션 ID 매핑, 작업본과 전송 증거, 감사 판독은 필요한 책임으로 유지했다.
- [작업본 계약](../coupang-api/working-copies.md), [전송 복구](../coupang-api/submission-recovery.md), [테스트 안내](../testing.md), [문서 목차](../README.md)를 현재 동작과 재현 명령에 맞췄다. 이전 날짜의 검증 사실은 수정하지 않았다.
- DB 마이그레이션·초기화를 추가하지 않았다. V1~V48, 보존 업무·역사적 지원 소스 380개와 쿠팡 SOURCE·원문·자산 1791개는 해시가 동일하다.
