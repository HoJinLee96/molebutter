# 사진 사이즈 이미지 고해상도·다중 비교 검증

실행일: 2026-10-21 (한국 시각). 실제 IDE 앱·운영 DB·쿠팡·R2 객체는 변경하지 않았다. Java 테스트는 격리 출력 디렉터리, 브라우저는 로컬 모의 API만 사용했다.

## 원인과 변경

사진 프리뷰와 저장 PNG는 기존 780×509px여서 최대 1180 CSS px 편집 화면에서 확대됐다. 사진 기반 편집은 1440×940 작업 좌표를 유지하면서 **2880×1880px로 직접 렌더링**한다. 치수 글자·선도 출력 해상도에서 그리며, 사진·비교 원본을 단계적으로 리샘플링하고 premultiplied alpha로 투명 가장자리의 검은 번짐을 방지한다. 일반 실루엣·고시 출력은 기존 780px를 유지한다. 원본 자체에 없는 디테일이나 압축 손실을 복원했다는 의미는 아니다. 기존 확정 이미지 바이트는 자동 변경하지 않으며 새로 생성·재편집한 결과부터 적용한다.

비교 선택을 최대 8종의 `layout.comparisons` 배열로 확장했다. 각각 ◆ 핸들로 이동하고 선택 목록에서 개별·전체 제거한다. 추가 대상은 기존 대상 오른쪽에 놓고 같은 높이 점선으로 실물 비율을 계산한다. 공간이 부족할 때는 전체 배율을 함께 조정한다. 과거 단일 `comparison`은 복원하며 명시적 빈 배열이 우선한다. 스냅샷·재진입에 배열 전체를 유지한다. 신규 DB 구조는 없다.
