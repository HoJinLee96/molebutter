# 2026-10-16 가격·재고 수정 모달 정리 검증

## 반영 내용

같은 옵션 관측 응답의 현재 가격·재고를 함께 표시하고 수정 대상 값을 강조한다. 사입가·변경 판매가격은 PC에서 나란히, 모바일에서 세로로 배치한다. 기본 계산은 마진 금액·비율만 표시하고 계산 판매가·제안가·목표 차이·VAT는 상세 계산에 둔다. 계산 공식과 서버 십진수 검증은 유지한다.

선정 매입처의 단일 정상 재고는 최신값 또는 마지막 정상 조회값을 입력한다. 조회 중·실패로 현재 관측이 비어도 동일 판매글의 과거 정상 관측을 DB에서 찾는다. 매입처 전체 옵션 수와 수량이 확인된 후보 수를 구분하며, 일부 옵션만 확인돼도 자동으로 단일 옵션으로 취급하지 않는다. 최신 옵션 구성이 남아 있으면 과거 재고도 정확한 옵션 ID로 제한한다. 이전값 표시의 확인 시각은 해당 조회 이력에서 읽으며 확인되지 않는 시각을 가격 확인 시각으로 대체하지 않는다. 선정 정보·재고·fingerprint는 하나의 읽기 전용 트랜잭션에서 조립한다.

미저장 직접 입력·저장된 해당 의도·자동 후보 순으로 복구한다. 캐시에 자동/직접 입력을 구분하며 사용자가 빈칸으로 만든 값도 보존한다. 재조회는 기존 미리보기를 무효화하고 입력을 보존한다.

`GET /api/coupang/products/{id}/options/{vendorItemId}/quick-edit/history?kind=PRICE|STOCK&page=0&size=20`을 추가했다. 기존 원문을 변경하지 않고 해당 옵션·항목으로 확인 가능한 관측·저장·실행 기록의 전후 숫자값만 추출한 뒤 서버에서 페이징한다. 요청·접수·미확인·조회 반영 완료를 구분하며 다른 옵션이나 항목의 전문을 응답하지 않는다. 이력 조회는 DB만 사용하고 모달 안에서 펼침·접기·실패 재시도를 제공한다.

공통 CSS에서 숫자 증감 화살표를 숨기고 원래 숫자 검증을 유지한다. 공통 상품 모달을 쿠팡 화면에 포함할 때 이미지 오류 이벤트가 쿠팡 표까지 가로채던 문제도 모달 내부로 범위를 한정해 수정했다.
