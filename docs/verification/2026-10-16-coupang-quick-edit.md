# 2026-10-16 쿠팡 상품 모달·옵션 빠른 수정 검증

## 구현과 범위

선정 매입처 코드에서 같은 쿠팡 페이지의 공통 상품 모달을 연다. 내부 상품 ID 안내와 상품 상세 링크를 제거하고 우측 가격수정·재고수정 버튼을 추가했다. 펼침 행 상하 패딩은 6px이며 여러 펼침·체크·검색·페이지를 보존한다. 공통 모달의 매입처 비교·선정·최신화·기본 편집·중첩 재고 모달·이력·통합 기능을 재사용한다.

빠른 수정은 기존 작업본에서 단일 옵션의 가격 또는 수량만 준비한다. 다른 수정 의도는 저장·전송 완료 뒤에도 남는다. 최초 저장·충돌 선택·revision·계정·옵션·UNKNOWN/ACCEPTED·중복 방지와 성공 의도 정산은 기존 실행 경로를 사용한다. 선정 근거 fingerprint와 설정 revision을 준비·실행 접수·dispatch 직전에 검사한다. DB repository의 예외 변환 때문에 검증 실패가 UNKNOWN이 되지 않도록 dispatch 검증을 repository 호출 전에 수행한다.

계산은 사용자 공식, 배송비 4,000원·수수료 10.5%·희망 마진 7%, 천 원 미만 버림과 만 원 단위 1,000원 추가 차감을 사용한다. 이전 사입가는 경고와 시각을 함께 표시하며 계산 가능하다. 이전·미확인 재고는 자동 제안하지 않는다. 공통설정에 앱 전체 계산값 저장·ADMIN 편집·revision과 변경 감사를 추가했다.
