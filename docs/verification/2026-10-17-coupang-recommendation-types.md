# 추천 비교 행·유형별 필터 검증 (2026-10-17)

## 변경

- 추천 표의 가격·재고를 ‘현재값 → 변경값 [수정]’ 한 줄로 표시한다. 변경값만 강조하고 28px/12px 수정 버튼으로 기존 모달을 연다. 제안·이전 가격 문구는 제거하고 이전 정상 사입가 여부·확인 시각은 툴팁과 접근성 설명에 보존한다.
- 가격 인하·역마진이면 가격 수정, 재고 보충이면 재고 수정만 표시한다. 무관한 항목은 현재값만 남긴다. 다중 옵션은 옵션 선택, 동일값은 중복 화살표 생략, 역마진 설정 검토 안내는 유지한다. 추천 전용 열 너비는 매입처 펼침 표에도 동일 적용한다.
- 추천 카드 아래에 전체·가격 인하·역마진·재고 보충 단일 선택과 전체 계정 건수를 표시한다. 검색·초기화·정렬·크기 변경·편집 복귀에 유형을 유지하며 다른 카드에서는 숨기고 필터를 보내지 않는다. 조회 실패는 직전 성공 유형·목록·집계를 유지한다.
- 목록 API reason=ALL|PRICE_HIGH|NEGATIVE_MARGIN|RESTOCK과 counts.recommendationReasons.priceHigh/negativeMargin/restock을 추가한다. 사유별 건수는 겹칠 수 있고 전체는 옵션당 한 번 집계한다. 계정 전체 판정 후 검색·유형 적용과 페이징을 수행한다. 기존 Search/Counts 생성자는 유지한다.
- 계산·선정 근거·단일 항목 저장·전송·UNKNOWN/ACCEPTED 보호를 유지하며 새 테이블·마이그레이션·주기 작업·외부 조회는 추가하지 않았다.

## 결과

- JavaScript 전체 225개 통과. 사유별 수정 표시, 동일값·미확인·재고 0·다중 옵션, 전역 집계, 유형 선택·검색·초기화·카드 전환·복귀·실패 복구를 포함한다.
- 관련 Java 21개 통과: 계산·추천·빠른 수정·소스 어댑터·모듈 경계·화면 렌더링 회귀.
- 임시 MySQL·Redis에서 30개 통과: CoupangRegisteredProductsIT 12, CoupangWorkingCopyFlowIT 18. 신규 유형 검사는 전체 30개 옵션, 가격 인하 10·역마진 10·재고 보충 20의 중첩 집계, 검색·정렬·필터 후 페이지, 특정 사유 해결 후 다른 사유 유지·집계 갱신, 잘못된 유형·그룹 거절을 포함한다.
- 추천 모의 화면 1920/1440/390px 통과. 한 줄 비교·28px 버튼·툴팁·접근성 설명, 무관한 버튼 제거, 유형 Enter/Space·건수·검색/초기화·실패 복구·수정 후 행 제거와 마지막 페이지 보정, 추천 상태의 매입처 열 정렬을 확인했다.
- 기존 매입처 펼침 및 빠른 수정 모의 화면 1920/1440/390px 통과. 입력 보존·UNKNOWN 보호·목록 상태·지연 응답 회귀를 포함한다.
- PC/모바일 추천 화면 캡처를 직접 확인했고 git diff --check 통과.
