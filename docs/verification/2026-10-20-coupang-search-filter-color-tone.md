# 검색필터 입력칸과 색상계열 선택 검증

2026-10-20 한국 시각 검증.

## 확인한 원인과 변경

첨부 화면은 검색어와 별개인 검색필터에 등록된 속성이 없다고 표시했다. 신규 등록 준비는 조회에서 확인한 값이 있는 속성만 채우며, 같은 카테고리의 초기 규격 조회는 입력칸이 없는 검색 속성을 추가하지 않았다. 따라서 카테고리에 선택 검색 속성이 있어도 신규 화면에서는 없다고 보일 수 있었다. 등록 후 현재 브라우저 화면을 읽기 전용으로 확인했을 때는 검색필터 17개가 표시됐고 값은 비어 있었다. 이는 API 원문을 직접 비교한 검증과는 구분한다.

카테고리의 `NONE` 검색 속성에 표시용 빈 입력칸을 만들고, 빈 자동 행은 저장 문서와 수정 의도에서 제외했다. 같은 이름의 구매 속성 `EXPOSED`와는 별개로 다루고, 기존 입력을 교체하지 않는다. 조회 중·실패·미조회·검색 속성 미제공 상태를 구분하며 실패 시 기존 입력과 재조회 동작을 보존한다.

사용자가 제공한 색상계열 14개를 고정 선택값으로 적용했다. 신규 준비는 노출상품명·상품 정보 도구 원문 제목을 순서대로 확인해 명확한 색상만 자동 선택한다. 화면의 제목으로 색상계열 선택 버튼은 현재 노출상품명·등록상품명으로 판단한다. 색상계열 충돌과 베이지·카키처럼 모호한 값은 비워 두고 수동 선택을 안내한다. 명시적 배색/멀티컬러/다색은 다색으로 연결한다. 제목 변경·재렌더링·기존 상품 조회만으로 기존 선택이나 직접 비운 값을 덮지 않는다. 버튼으로 다른 값을 적용할 때는 교체 확인을 받는다.

현재 목록에 없는 과거 값도 읽기·저장 시 자동 변환하지 않는다. 카테고리 필드명 및 `NONE` 구분이 일치할 때만 적용한다. 색상계열 선택값은 이번 사용자 지정 계약이며 카테고리 메타정보 API가 14개 후보를 직접 반환한다고 주장하지 않는다. 보관된 카테고리 SOURCE의 `EXPOSED`/`NONE` 구분 및 승인 후 속성 변경 제한을 확인했으며 문서를 변경하지 않았다.

Java와 JavaScript는 같은 14개 목록·23개 제목 판단 사례를 사용해 결과를 대조했다. 신규 준비는 명확한 원문 제목의 브라운 톤 입력, 충돌/모호한 색상 미입력을 검사했다. JS 단위 검사는 초기 검색 속성 입력칸의 중복 미생성, 빈 자동 행의 수정 의도 미생성 및 직접 입력한 `NONE` 행만 저장되는 것을 확인했다.

모의 화면은 CREATE/UPDATE 모두에서 선택값 14개, 제목에 의한 선택, 직접 선택 보존, 교체 취소, 모호한 제목, 저장·새로고침, 목록 밖 기존 값 보존, 조회 실패 후 재조회, 검색 속성 미제공 상태를 검사했다. 기존 구매/검색 속성의 동일 이름·권한·택1·미리보기 회귀도 통과했다. 격리 DB는 자동 입력한 `브라운 톤`의 작업본 저장·재진입 보존 및 기존 계정·revision·UNKNOWN·ACCEPTED 보호를 검사했다.

명령은 `./mvnw -o -Dmolebutter.build-directory=target/color-tone -Dtest=CoupangColorToneTest,CoupangPrefillServiceTest,LayoutViewTest -Dsurefire.failIfNoSpecifiedTests=false test`, `node --test src/test/js/*.test.cjs`, `bash scripts/test-integration.sh -Dtest=CoupangWorkingCopyFlowIT -Dsurefire.failIfNoSpecifiedTests=false`, `node scripts/test-coupang-attribute-identity.cjs`, `node scripts/test-coupang-prefill-ui.cjs`다. 외부 쓰기는 비활성화하고 Java 출력은 IDE 경로와 분리했다.

운영 DB·실행 중인 IDE 앱·실제 쿠팡 상품값·R2 객체를 변경하지 않았다. 브라우저에서는 현재 화면을 읽기만 했으며 입력·저장·새로고침을 하지 않았다. 새 API·테이블·마이그레이션은 없다. 앱 재시작 후 새 등록 준비부터 자동 입력이 적용되며, 기존 상품은 사용자가 버튼/선택창으로 입력하고 명시적 반영 절차를 진행한다.
