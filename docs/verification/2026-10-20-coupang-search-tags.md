# 검색어 자동 입력·재생성 검증

검증일: 2026-10-20 한국 시각.

## 구현

신규 상품 정보 도구 등록 준비와 명시적인 검색어 재생성이 동일한 쿠팡 모듈의 순수 생성기를 사용한다. 노출상품명 단어·색상·브랜드 표기 변형·종류·성별/수령 대상·소재·직장 관련·공통 용도/스타일 순서로 중복을 제거하고 최대 20개, 각 20자를 적용한다. 제외 사유는 `OVER_COUNT`, `OVER_LENGTH`이며 임의 절단을 하지 않는다. 명확하지 않은 성별, 다른 브랜드의 표기 변형, 다른 상품 종류, 합성가죽/나일론의 소가죽 확장을 하지 않는다.

최초 준비 응답의 선택적 `searchTagContext`를 추가하고 기존 `registration.searchTags`에 쉼표 구분값을 채운다. 원래 조회 상품코드나 저장용 코드에서 색상·성별을 추정하지 않는다. 제조사·제품명·배송비 등 기존 자동 입력 변경을 보존한다.

`POST /api/coupang/working-copies/search-tags`는 편집 권한 및 기존 CSRF 보호를 사용한다. 입력은 제목·브랜드·색상/분류 근거이고 결과는 검색어와 제외 사유다. DB 저장·외부 조회·전송·감사 기록 작성을 실행하지 않는다. app이 imaging 근거를 조립하며 쿠팡 모듈에 imaging 의존성을 추가하지 않았다. 새 테이블·마이그레이션은 없다.

편집기의 검색어 다시 만들기는 직접 편집값(삭제해 빈 값인 경우 포함)과 기존 옵션별 검색어의 교체 확인을 받는다. 현재 색상 속성을 이전 고시/조회값보다 우선하며, 색상을 변경·제거한 뒤 이전 색상이 복원되지 않게 한다. 브라우저 캐시에 근거와 편집 여부를 기존 사용자·계정·작업본/토큰 키와 함께 보관한다. 응답 도착 전 제목·색상·검색어·계정/세션·작업본/revision이 달라지면 적용하지 않는다. 자동 재렌더링으로 검색어를 갱신하지 않으며 취소·실패·지연 응답에서 입력을 보존한다.

Java 검사는 계획의 정확한 20개 예제 및 클래식 제외, 제목·색상 우선순위, 긴 단어·중복·특수문자만 있는 조각, 성별 상충, 현재 제목으로 이전 분류/소재 갱신, 상품군별 종류, 소재 오인 방지, 루이까또즈 표기 변형 한정, 입력 크기 제한을 검사했다. 실제 서버 조회의 색상과 생성된 화면 표시명/상품코드의 분리를 검사하고 편집 권한 거절 시 생성기 미실행을 확인했다.

작업본 격리 검사는 검색어 생성 전후 행 미생성 및 생성한 검색어의 임시 저장·재진입 보존을 확인했다. 기존 계정·revision·UNKNOWN·ACCEPTED·충돌 회귀도 통과했다. `CoupangWorkingCopyWriteTest`는 기존 전송 준비와 모의 실행에서 검색어가 문자열 배열로 변환되고 미수정 원문 필드가 보존되는 것을 검사했다.

PC/모바일 검사는 최초 자동 입력, 제목/색상 변경만으로 검색어 미변경, 입력창 Enter 미실행, 직접 검색어·빈 검색어의 교체 취소, 생성 실패, 처리 중 중복 클릭 방지, 지연 응답 중 제목/검색어 변경 보존, 현재 색상 적용, 색상 제거 후 이전 색상 미복원, 새로고침 보존 및 기존 토큰/사용자 격리를 검사했다. 생성 영역의 모바일 스크린샷을 확인했고 가로 넘침이 없음을 검사했다. 화면의 생성 API는 모의 응답이며 선정 규칙 자체는 Java 생성기 검사로 검증했다.

## 명령과 경계

- `./mvnw -o -Dmolebutter.build-directory=target/search-tags verify`
- `node --test src/test/js/*.test.cjs`
- `bash scripts/test-integration.sh -Dtest=CoupangWorkingCopyFlowIT -Dsurefire.failIfNoSpecifiedTests=false`
- `node scripts/test-coupang-prefill-ui.cjs`

Java 21, 외부 쿠팡·주문 쓰기 및 R2 비활성 환경에서 실행했다. Java 출력은 IDE 빌드 경로와 분리했다. 보관된 쿠팡 상품 생성 및 검색어 FAQ SOURCE의 20개/20자 규칙을 확인했으며 원문을 변경하지 않았다. 보관 문서 수집일과 이번 모의 검증일은 구분한다.

운영 DB·실행 중인 IDE 앱·실제 쿠팡 상품값·R2 객체를 변경하지 않았다. 앱 재시작 후 새 등록 준비부터 최초 자동 입력이 적용된다. 기존 상품·작업본·미저장 입력에는 자동 적용하지 않는다. 실제 계정의 검색어 수용이나 검색 노출 개선을 검증한 결과는 아니다.
