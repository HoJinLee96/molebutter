# PR #35 V47 중복 미디어 보존 수정

검토 기준은 `16f89813`이며 실행일은 2026-10-16(KST)다. 이전 [현재 앱 검증 기록](2026-10-16-coupang-final-review.md)과 구분하며, 이 문서는 V46→V47 전환 결함의 후속 수정·실행 결과다.

## 변경과 보존

저장된 수정 의도가 없는 V46 연결 상품에서 같은 URL 이미지·같은 본문 설명을 첫 기존 ID로 반복 매칭해 V47이 업무 DDL 전에 실패하는 결함을 재현했다. 적용된 V47 소스·역사적 판독 시그니처·Flyway 이력은 변경하지 않았다.

백업·격리 복원을 확인한 V47 유지보수 명령이 서버 조회 원본과 옵션 매핑에서 전환용 관측 입력을 준비한다. `changes`는 빈 목록이며 기존 사용자 수정 의도와 원문을 덮어쓰지 않는다. 현재 편집기와 같은 순수 함수가 기존 미디어를 한 번씩 사용해 ID를 보존하고 역할·세부 타입과 신규 행 ID 충돌을 처리한다. 정확한 공개 주소일 때만 로컬 파일 참조를 유지한다.

불변 V47 판독기로 전환한 뒤 이번에 준비한 입력만 바이트 단위로 대조해 제거한다. DB의 대소문자 무시 비교로 변경된 입력을 삭제하지 않는다. 원래 초안·수정 의도·이미지 참조·공개 토큰·전송 전문·해시·중복 방지 키는 보존한다. 준비 ID는 사전 보고서에 남긴다.

사전 검사 실패는 준비 트랜잭션을 롤백한다. 준비 커밋 이후 중단되거나 완료 대조가 실패해 표식이 남으면 V47·V48 유지보수 명령이 거절한다. 이 경우 준비 전 전체 DB·파일 백업을 복원한다. 자동 기동 전환이나 V49로 우회하지 않는다. 운영 절차는 [V47](../coupang-working-copy-migration.md)과 [V48](../coupang-intent-migration.md)을 따른다.

## 직접 실행한 검증

- 전체 Maven `verify`: **718개**, 실패·오류·생략 0. 모듈 경계와 공개 계약 검사 포함.
- 전체 격리 MySQL·Redis 통합 프로필: **954개**, 실패·오류 0, 실계정 조건 **5개 생략**. 실행한 Java 검사는 949개다. 단위 검사를 포함한 수이며 IT 부분집합 236개를 별도 합산하지 않는다.
- JavaScript **190개** 통과. Chrome **1440px·390px**에서 쿠팡 기본 편집·신규 복구·수정 의도·저장/완료 경합·전송의 **5종 스크립트** 통과. 입력 Enter 쓰기 금지와 버튼 Enter·Space, 실패 후 입력 보존 포함.
- `CoupangV47PreparationIT`: 기존 실패 재현, 실제 V47→V48 전환, 중복 미디어의 ID·로컬 참조, 최신 조회 이름·가격, 실제 저장 가격 의도 130000 보존. 활성 임대·계정 불일치·중복 상품·잘못된 채널·조회 원본 누락은 변경 없이 거절. 중단 표식과 대소문자만 바뀐 준비 입력도 감지.
- 기존 작업본 저장·세션 복구·중복 미디어 재진입·완료 직후 저장 경합·계정/revision/옵션 보호·UNKNOWN 결과 확인 검사 통과. 가격 `120000 → 사용자 130000 → 외부 150000 → 요청 130000`과 미수정 원문 보존 검사 포함.
- `test-coupang-working-copy-upgrade.sh`: 합성 V46 DB와 가짜 이미지로 실제 명령의 전체 dump·격리 복원·이미지 백업·중복 미디어 전환·원래 감사 지문·UNKNOWN 실행 증거·반복 실행 확인.
- `test-coupang-intent-upgrade.sh`: V48 명령의 전체 백업·격리 복원·감사 이력·이미지·전송 증거 보존·반복 실행 확인.
- 실행 JAR의 격리 HTTP 기동·CSRF·쿠팡 자원·복구 미리보기, 업무 라이브러리 11개, 비밀 파일·테스트 자료 제외 확인. 최종 준비 클래스의 바이트 대조 포함.

합성 DB·가짜 파일·모의 API만 사용했다. 위 중단 표식 검사는 DB 상태와 재진입 거절 검사이며 실제 호스트 전원 차단 검사는 아니다. 실제 쿠팡 쓰기와 공용 R2 쓰기·삭제는 실행하지 않았다.
