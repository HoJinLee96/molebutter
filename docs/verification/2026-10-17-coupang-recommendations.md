# 쿠팡 추천 카드 검증 (2026-10-17)

## 구현

- 상품 → 추천 → 판매중 → 품절 → 판매중지 → 삭제 순서. 최초 진입은 판매중이다. 추천 검색·초기화는 추천 범위를 유지하고 다른 카드 클릭으로 범위를 전환한다.
- 현재 계정의 판매 중 옵션 전체를 가벼운 투영으로 읽어, 최종 제안 가격보다 높은 가격·반올림 전 역마진·최신 구매 가능 재고에 따른 품절 보충을 독립 판정한다. 복수 사유는 한 옵션으로 집계한다. 검색과 무관한 counts.recommended를 제공하며 검색·정렬 후 추천을 필터링하고 페이징한다. 상세는 현재 페이지에서만 읽는다.
- 활성 내부 상품의 전체 코드 정규화·바이너리 정확 일치·유일성을 사용한다. 중복·삭제·병합·선정 미발견·조회 기준 변경·매장 충돌을 제외한다. 기존 마지막 정상 가격은 허용하고 이전 가격을 표시한다. 재고는 최신 정상 결과의 구매 가능 양의 수량만 사용한다. 대기·실패·미확인·이전 재고는 추천 근거로 사용하지 않는다.
- 동일 요청의 설정·쿠팡 옵션·선정 근거를 읽기 전용 REPEATABLE_READ 트랜잭션에서 조회한다. 쿠팡 공개 포트 → 앱 어댑터 → 매입 공개 코드 일괄 조회로 연결하고 쿠팡 모듈의 매입 의존성을 추가하지 않았다.
- 추천 사유·제안·가격수정/재고수정 버튼을 기존 표에 표시한다. 다중 옵션은 자동 합산하지 않고 모달에서 선택한다. 수량 미확인 옵션도 구분하고 선택 시 빈칸을 유지한다. 제안 가격에서도 손실이면 설정 검토를 안내한다.
- 기존 단일 항목 저장·전송과 충돌·revision·관측·선정 근거·설정 검사, UNKNOWN/ACCEPTED 보호를 유지한다. 반영 완료·선정 변경 후 추천을 재판정하고 제거된 마지막 페이지를 보정한다. 실패는 직전 결과와 건수를 보존한다.
- 기존 API 확장만 사용하며 영구 연결·새 테이블·마이그레이션·자동 변경·주기 작업을 추가하지 않았다.
