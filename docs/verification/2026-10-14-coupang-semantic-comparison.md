# 쿠팡 실제 적용값 기준 비교

대상: 공통 상품 `897779631605467192` / `WCWA705R2`. ESM 제외. 실제 마켓 상품 등록·수정·이미지 업로드는 금지하고, 파일 읽기·마켓 조회·내부 저장만 검증한다.

## 구현

- 쿠팡 `itemName`은 내부 관리용 옵션명 비교에서 제외한다. 연결은 기존 외부 옵션 ID와 공통 옵션 UUID를 유지한다.
- 구매·검색 속성은 `name + exposed`로 비교하며 배열 순서를 무시한다. 같은 키의 중복 속성은 합치지 않고 확인 정보로 표시한다. 보관 변경의 재비교에도 같은 속성 기준을 적용한다.
- 공통 이미지·설명은 옵션별 최종 적용 목록으로 한 번만 비교한다. 공통 상속 여부를 표시하고, 옵션 채택·재적용은 공통 원본과 다른 옵션을 변경하지 않는다.
- 이미지 역할·대표 지정·순서·개수와 설명 본문 구조는 비교한다. UUID·자산 ID·CDN 주소는 동일성의 근거로 사용하지 않는다. 파일 SHA-256 또는 디코딩한 ARGB 픽셀 지문이 같을 때 동일하다고 판정한다.
- 확인된 원본/CDN 쌍의 한쪽 내용이 나중에 바뀌면 차이로 판정한다. 최초 파일 차이가 압축 변환인지 입증되지 않거나 파일 접근에 실패하면 `UNVERIFIED` 확인 정보로 표시하고 선택을 차단한다. 차이가 확정되지 않은 정보는 일반 수정의 검증 완료·전송을 차단하는 오류로 만들지 않는다.
- 이미지 원본은 R2 또는 기존 앱 자산에서 읽고, 기존 CDN은 허용된 호스트의 HTTPS 경로만 제한된 크기·시간으로 읽는다. 같은 참조는 조회 한 번에 한 번만 읽는다. 공개 자산 발급·네이버 업로드를 수행하지 않는다.
- V44 `marketplace_media_comparison`에 계정·상품·연결 세대·옵션 UUID·이미지/설명별 파일 지문, 공통/개별 출처와 원본 ID를 보관한다. 실제 전송 문서에서 같은 원본 참조가 확인되는 경우만 실행 ID를 연결한다. 이전 실행 문서나 공통 원본은 수정하지 않는다. 네트워크 읽기는 편집 트랜잭션 밖에서 수행하고, 늦은 조회는 revision·연결 세대 확인 후 보관한다.
- 쿠팡 소재·제조국·공통 A/S 안내는 비교에서 제외하며 실제 상품고시는 기존 별도 경로를 유지한다. 앱 저장 의도가 없고 조회값도 null·빈 문자열·빈 목록이면 행을 생략한다. 0·false는 빈값으로 취급하지 않는다.
- 정상가는 `Option.originalPrice`와 쿠팡 등록 설정을 최종 적용값 한 항목으로 투영한다. 기존 알려진 저장 항목 또는 동일 연결·세대의 신뢰할 전송 문서로 저장 의도가 확인되는 경우만 비교한다.
- 최저가 보장·바코드 없음·바코드 미등록 사유·상품 상태 등 실제 항목명과 `예/아니요/새 상품` 표시를 사용한다. 자동 가격 조회 전용 정보는 제외하고, 등록 후 바꿀 수 없는 상품 상태는 앱 채택만 허용한다.
- 비교 정책 버전 2와 파일 증거 토큰으로 오래된 선택을 차단한다. 선택 직전 다시 읽은 동일 URL 파일의 내용이 달라져도 재비교하며 입력을 보존한다.
- `Media.imageOverrides/contentOverrides`는 빈 개별 목록을 공통 상속과 구분한다. 구문서의 누락 맵은 기존 병합 규칙으로 읽는다. 공통 이미지 한 장을 편집할 때 다른 상속 이미지도 개별 최종 목록에 함께 보존한다. 옵션 삭제 시 관련 맵 키만 정리한다.

## 계약 근거

프로젝트 현재 SOURCE: `marketplace-api-docs/coupang/api/products/querying-product.md`의 itemName·originalPrice·images·attributes·contents. vendorPath 자동 다운로드/CDN, 속성의 구매·검색 구분 및 승인 후 추가 조회 속성, originalPrice 할인율기준가를 구분했다. 상품 상태는 생성 후 변경 불가인 기존 계약을 비교 재적용에도 반영한다. API 계약 자체나 ESM 연동을 확장하지 않았다.
