# 가격·재고 빠른 수정 단일 저장 검증 (2026-10-17)

## 변경

- 코드·옵션과 현재 가격·재고를 두 줄로 구분하고 대상 종류를 강조한다. 사입가 아래에 적용 설정, 변경 판매가격 아래에 마진을 배치한다. 모바일은 입력과 설명을 묶어 세로 배치한다.
- 설정 이동 링크·제안 가격 사용·전송 체크박스·별도 전송 버튼을 제거한다. 사입가 변경 시 제안 가격을 자동 적용하며 직접 판매가격을 수정할 수 있다. 빈/비정상 사입가는 판매가격을 덮어쓰지 않는다.
- 저장 버튼 옆에 현재값 → 입력값을 표시한다. 같은 값은 요청을 생략한다. 클릭 후 기존 prepare로 저장·검증하고 변경 전후 값·관측 버전·단계 종류·옵션이 일치할 때만 execute로 이어진다. 충돌과 서버 검증 문제는 모달 안에서 처리하고 자동 전송하지 않는다.
- 실행 전에 계정·상품·옵션·종류로 구분한 sessionStorage에 준비 ID·idempotency key를 저장한다. 저장소 실패는 전송을 차단한다. 실행 응답 유실은 결과 확인 버튼으로 같은 ID·키를 사용해 복구하며, 실행 ID가 있으면 재진입 시 GET으로 복구한다. 명확한 4xx 거절은 입력을 보존해 재확인을 요구한다. 요청 접수·UNKNOWN·반영 확인 완료를 구분한다.
- 전송 중 작업본의 최신 관측값이 유효하면 quick-edit 문맥을 조회할 수 있게 했다. registry.blocked는 유지하므로 새 준비·전송은 차단되고 기존 실행 확인만 가능하다. 관측값이 없는 편집 실패는 계속 거절한다.
- 공개 API·DB 구조·마이그레이션은 추가하지 않았다. 전체 편집기의 별도 미리보기/전송 확인 동작은 유지한다.
