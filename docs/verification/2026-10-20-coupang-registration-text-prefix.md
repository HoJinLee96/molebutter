# 2026-10-20 등록 자동 입력·공통 상세설명 이미지 검증

## 변경 사항

- 상품 정보 도구의 서버 관측에 원래 상품명을 보존한다. 등록 제목은 브랜드 → 성별 → 소재 → 특징 → 구체 카테고리 순서로 만들고, 원문·고시·분류에 없는 항목은 생략 안내한다. 화면 표시용 이름의 코드 기반 성별 추정이나 사진·외부 AI는 사용하지 않는다. 일반상품명은 브랜드 제외, 등록상품명에만 판매자상품코드 접미사를 넣는다. 제조사는 공백·괄호 정규화한 고시 항목명으로 조회하며 누락·충돌은 안내한다.
- 정상가·판매가의 공백·쉼표를 클라이언트와 서버의 저장·미리보기·모의 전송에서 정리한다. 등록/수정, 개별/일괄 가격 입력에 적용한다. 문자·소수·음수·지수 표기 검증을 유지하고, 없는 필드와 빈 필드를 구분한다. 같은 가격의 서식 변경은 새 의도를 만들지 않되 기존 서버 보관 미완료 의도는 유지한다. 기존 원문·관측·실행 증거를 변경하지 않는다.
- 공통 등록 설정 GET/PUT에 `descriptionPrefixImages`를 추가했다. 순서 있는 최대 20개 URL이며 기존 V51 JSON에 보관한다. 이전 PUT의 필드 누락은 기존 목록 유지, `[]`는 해제다. 계정·revision 검사를 유지한다.
- 공개 R2의 설정된 origin과 `common/` 경로에서 실제 이미지·상세설명 규격을 검사한다. 다른 도메인·경로 이동·비공개 경로를 허용하지 않는다. 이미지 쓰기는 없다. 새 등록 준비에서 공통 이미지를 기존 설명 앞에 넣고 대표·추가 이미지에는 넣지 않는다. 저장 후 삭제·조회 실패에도 행을 보존해 전송 전 검증을 받는다.
- 설정 UI에서 추가·삭제·위/아래 이동을 지원한다. URL 예시는 자동 저장하지 않는다. 실패·revision 충돌은 미저장 입력을 유지하고 Enter는 저장하지 않는다. 기존 상품·작업본·준비된 토큰에 공통 이미지를 소급 적용하지 않는다.
