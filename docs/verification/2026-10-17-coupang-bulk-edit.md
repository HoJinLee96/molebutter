# 현재 페이지 전체 선택·쿠팡 일괄 수정 검증 (2026-10-17)

## 적용

- 행 선택이 있는 상품 목록·쿠팡 목록·일괄 수정 모달에 공통 TableSelection을 적용했다. 전체 선택은 현재 페이지의 활성 행을 대상으로 하며 전체·일부·선택 없음 상태를 동기화한다. 조회 전용 표에는 선택 열을 추가하지 않았다.
- 쿠팡 조회/선택 요약 오른쪽에 가격 변경하기·재고 변경하기를 배치했다. 현재 페이지에서 선택한 상품의 보이는 옵션을 모달에서 확인하고 옵션별 추천값을 수정·제외할 수 있다.
- 저장은 기존 단일 항목 준비·실행을 순서대로 처리한다. 동일값은 생략하고 revision·관측·설정·근거 변경 및 준비 범위 불일치에서는 전송을 멈춘다. 준비 ID·중복 방지 키를 먼저 보관하고 응답 유실·재진입은 같은 실행을 복구한다. ACCEPTED/UNKNOWN/실패에서는 후속 항목을 중단한다.
- 기존 API와 DB 구조를 사용하며 신규 엔드포인트·마이그레이션은 없다.
